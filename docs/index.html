Context-aware vulnerability prioritization

Find what matters, not just what scans

VulnX is a web-based security assessment platform. It discovers services, correlates CVEs, surfaces Metasploit candidates, and ranks every finding by the real risk to your assets, not by CVSS alone.

Download VulnXView on GitHub

Free and open source. Runs on Windows, macOS, or Linux.

What is VulnX

One platform for the full vulnerability assessment workflow.
◉

Network scanning

Nmap discovery with service and version detection, parsed into structured findings.

⚑

CVE intelligence

Live NVD correlation with CPE version applicability, so a match is evidence, not a guess.

▲

Context-aware risk

Asset criticality, network exposure and service importance reprioritize findings per host.

⚙

Metasploit intelligence

Module discovery for candidate identification. VulnX never auto-runs exploits.

▤

Web & reporting

Passive web checks, an attack-surface map, charts, scan history, and PDF export.

📊

Why it is different

The same CVE ranks higher on a critical internet-facing asset than on a throwaway lab box.

How it works

A single assessment pipeline, from target to prioritized report.
Target→ Nmap scan→ Parse services & CPEs→ NVD CVE correlation→ Context-aware risk engine→ Metasploit intelligence→ Report & history

Get started

Runs on Windows, macOS, or Linux through Docker. No Kali setup required.

  1. Install Docker

    Download and install Docker, then make sure it is running.

    Docker Desktop (Windows / macOS) Docker Engine (Linux)

  2. Get the VulnX project

    Download the project as a ZIP and unzip it, or clone it with git. Either way you get a folder containing the Dockerfile and docker-compose.yml.

    Download ZIP 
    git clone https://github.com/raghavsharma131813-cmyk/vulnx.git
cd vulnx

  3. Build and run

    From inside the VulnX folder, run one command. The first build installs Metasploit and can take 10 to 20 minutes.

    docker compose up --build

  4. Open and scan

    Open the app in your browser. For a safe first test, scan 127.0.0.1 with the Kali SSH Password kali.

    http://localhost:5000
Authorized use only. Only scan systems you own or have explicit written permission to test. Scanning systems without authorization is illegal in most countries. VulnX performs intelligence and discovery only and never automatically runs exploit modules.
